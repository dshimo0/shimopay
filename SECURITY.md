# Security

Please report vulnerabilities privately to shimopay@pm.me. Do not include secrets in public issues.

Use only localnet, Devnet and provider test accounts. Do not fund deterministic fixtures or shared demo wallets with real assets. The hosted prototype does not implement production user isolation, wallet ownership or personal transaction PINs.

[Protocol security model](docs/SECURITY_MODEL.md) and [limitations](docs/LIMITATIONS.md) describe the threat model. Automated checks are not an independent security audit.
